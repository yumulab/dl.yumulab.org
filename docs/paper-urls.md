# 論文詳細URLの対応表

URLはサイトのルートを基準に表記しています。現在の仮URLでは、先頭に `https://yumulab.github.io/dl.yumulab.org` が付きます。独自ドメイン移行後は `https://dl.yumulab.org` が付きます。

例: `/papers/77/` → `/papers/ec79-miyazaki/`。既存の数字URLは、新URLへ即時転送するHTMLページとして残します。

## 管理方法

`src/data/paper-slugs.json` がURLの確定値です。著者表記・会議略称の変更や現行サイトからのデータ再取り込みでは、確定済みのURLを再計算しません。新規論文の追加時は、数字IDに対応するURL名も同ファイルへ追加してください。

PDFとサムネイルのファイル名は内部IDを引き続き使用するため、この変更では移動していません。
